## What it is
SP 800-171A "provides organizations with assessment procedures and a methodology that can be used to conduct assessments of the security requirements in NIST Special Publication 800-171" (CSRC abstract). Each procedure has an assessment objective made of determination statements and ODP determination statements, and assessment methods "include examine, interview, and test" (Sec. 2). Each determination statement yields a finding of "satisfied" or "other than satisfied" (Sec. 2).

## Who it applies to
Organizations and assessors evaluating implementation of SP 800-171. "Assessments can be conducted as independent, third-party assessments or as government-sponsored assessments" (CSRC abstract). It has force only where a contract or regulation calls for it (e.g., CMMC uses SP 800-171A Jun2018 for Level 2 assessment objectives).

## Engineering obligations
800-171A does not add requirements; it defines the evidence an assessor will look for. Engineering-relevant implications:

| ID | Obligation | Official reference |
|---|---|---|
| A-ODP | Define and document a value for every organization-defined parameter before assessment (e.g., A.03.01.01.ODP[05] inactivity time before logout) | Sec. 2; A.03.01.01.ODP[01..] |
| A-DET | Produce evidence for each determination statement (e.g., A.03.01.01.b[01]-[04]: accounts created, enabled, modified, disabled per policy) | A.03.01.01 |
| A-EXAM | Keep reviewable artifacts (policies, procedures, SSP, configuration settings, logs) for the examine method | Sec. 2 (assessment methods) |
| A-INT | Staff able to explain implemented controls for the interview method | Sec. 2 |
| A-TEST | Systems testable by assessors (mechanisms exercised under operating conditions) for the test method | Sec. 2 |
| A-INHERIT | Document security capabilities inherited from shared/external providers so assessors can trace them | Sec. 2 |

## Assessment and certification
Used by self-assessors, third-party assessors and government assessors. Under CMMC, C3PAOs and DCMA DIBCAC apply the assessment objectives of "NIST SP 800-171A Jun2018" (32 CFR 170.4, definition "Assessment objective"; IBR at 170.2(b)(10)). No certificate is issued by NIST.
